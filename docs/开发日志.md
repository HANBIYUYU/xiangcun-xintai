## P1 数据库 ✅（commit `a379c76`）

- 阻碍 1：`wrangler d1 migrations apply` 会把 `migrations/` 下所有 `.sql` 视为迁移，种子文件被当成迁移自动应用，导致 `db:seed` 重复执行时撞 UNIQUE 约束。
  - 解决：种子移出 `migrations/` 至 `apps/api/seeds/seed.sql`，`db:seed` 单独执行。
- 阻碍 2：遗留的 `wrangler dev` 进程锁定本地 D1 文件（Windows 无法删除被占用文件），且 WMI 查询被沙箱拒绝。
  - 解决：用 WMI 提权查询进程命令行定位到 `wrangler dev`，停止后删除 `.wrangler/state/v3/d1` 重置，再重跑 migrate+seed。

## P2 API 基础 ✅（commit `266127b`）

- 阻碍：本地开发环境（http://127.0.0.1）下登录 Cookie 无条件带 `Secure` 标志，浏览器不保存 → 本地登录失效。
  - 解决：`ENVIRONMENT === 'production'` 时才加 `Secure`，dev 不加；登录/登出两处同步修改，curl 冒烟验证通过。

## P3 前端框架（进行中）

- 阻碍：`apps/web` 首次 `tsc --noEmit` 报 13 处 TS2739 —— `@ant-design/icons@5.3` 的图标 props 类型缺少 `onPointerEnterCapture/onPointerLeaveCapture`，与 `@types/react@18.3` 不兼容（P0 只经 vite/esbuild 构建未做类型检查，故遗留）。
  - 解决：升级 `@ant-design/icons` 至 `^5.6.1`，全量 `tsc --noEmit` 通过。
- 产出：`apps/web/src/api/index.ts` 补齐 14 组资源 API（auth/stages/red-plays/articles/activities/submissions/suggestions/quiz/study-plans/bookings/study-results/products/orders/coupons/faq/news/stats/upload），公开接口支持 `skipAuthRedirect` 避免游客操作被强制跳登录；`AdminLayout` 菜单按 team/admin 角色动态渲染。
