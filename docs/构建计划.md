# 湘村新台——桂阳古戏台红色文旅数字官网 · 初次构建计划 v0.2

> 项目目录：`Xiangcun_guilin` ｜ 依据文档：《初步构建》｜ 版本：v0.2
> **v0.2 变更**：决策升级为「一步到位真后端」；技术栈采用 **Cloudflare 全家桶**（Pages + Workers + D1 + R2 + KV），**架构与前端设计全面对标工作区 `mili-edu` 项目**（pnpm monorepo：`apps/web` + `apps/api`）。

---

## 1. 项目定位

| 项目 | 决策 |
|---|---|
| 产品形态 | 响应式网页（手机 / 电脑浏览器直接访问） |
| 技术路线 | **对标 mili-edu**：pnpm monorepo，`apps/web`（React + Vite + Ant Design）+ `apps/api`（Cloudflare Workers + Hono + D1） |
| 后端方案 | **真实后端**：游客投稿、审核、预约、订单、留言全部写入 Cloudflare D1 数据库，跨设备可见 |
| 认证与权限 | JWT（httpOnly cookie）+ **三级权限**：游客 / 项目团队 / 政企文旅管理员（mili-edu 为单管理员，此处扩展 role 字段） |
| 素材方案 | 图片用主题色 SVG 占位；**文件上传走 R2**（若支付方式未开通则先用"外链 URL 录入"过渡，见 §8 风险） |
| 部署方案 | `wrangler deploy`（API）+ `wrangler pages deploy dist`（Web），域名可绑 `*.pages.dev` 或自有域名 |
| 成本 | Cloudflare 免费额度：Workers 10 万请求/天、D1 5GB、Pages 无限静态、KV 免费 — **0 元起步** |
| 目标 | 九大模块全部有入口且**前后端真实跑通主流程**（投稿→审核→展示、预约→订单、答题→优惠券），移动端可用 |

## 5. 数据库设计（D1 migrations，SQLite）

| 表 | 关键字段 | 说明 |

| `admins` | username, password_hash, **role**(`team`/`admin`), created_at | 三级权限中的两级管理角色 |

| `red_plays` | title, category(折子戏/演出视频), iframe_src(白名单), cover_url, sort_order | 红色戏曲 |
| `articles` | title, content, cover_url, source(公众号), sort_order | 互动阅读 |
| `activities` | title, type(红色党课/非遗体验/戏曲汇演), place, start_time, end_time, status | 活动排期 |
| `submissions` | author_name, contact, type(老照片/口述/短视频), content, media_url, **status(待审核/已通过/已驳回)**, created_at | 游客投稿 + 审核流 |

| `quiz_questions` | question, option_a/b/c/d, answer, explanation, stage_id | 题库（种子 ≥40 题） |
| `bookings` | org_name, contact, plan_type, people_count, duration, target_stage, note, status | 研学预约单 |
| `study_plans` | title, type(中小学思政/高校实践), schedule, courseware, teachers, cover_url | 套餐 |
| `study_results` | title, org_name, content, images, created_at | 成果展示 |

## 7. 真实数据接入规范

- **戏台台账 Excel/CSV** → 一次性脚本或后台导入到 `stages` 表（字段见 §5，坐标 `lng/lat` 为真实地图预留）
- 素材命名：`模块_类型_编号`（如 `stage_photo_001.jpg`），存 R2 `assets/` 前缀下
- 视频嵌入白名单：`player.bilibili.com`、`v.qq.com`、`www.youtube.com`（沿用 mili-edu 做法）

## 8. 风险与对策

| 事项 | 状态 | 对策 |
|---|---|---|
| **R2 上传需支付方式**（mili-edu 已验证的阻塞点：外币卡） | 高风险 | 上传 API 先返回 stub（照搬 mili-edu 现状）；管理端支持**直接录入外链 URL**（如公众号图床、对象存储公开链接），功能不受阻；开通支付方式后启用 R2 |
| 视频/音频素材缺失 | 待定 | 视频用封面 + 外链 iframe 白名单；口述音频先用占位按钮 |
| 3D 真实建模 | 待定 | 程序化占位模型，后续替换 glb |
| 三级权限复杂度 | 可控 | 在 mili-edu 单角色基础上加 `role` 字段 + 路由守卫，不做复杂 RBAC |
| 企微通知（mili-edu 待办） | 不纳入 | 投稿/预约通知先做站内"待处理"红点，webhook 后续可选 |
| 线上支付 | 不纳入 | 下单 = 预约单 + 线下自提/同城配送，优惠券码抵扣 |
