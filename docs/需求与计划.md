## 1. 需求（九大模块）

> 原文标注：黑色体尽量实现（有入口即可）；灰色/括号内为可暂缓项。当前 P0–P12 已全部实现入口与主流程，剩余为真数据填充与打磨。

1. **首页·总门户**：红旅主题视觉（红色戏台 + 湘昆非遗双主线）；四大快捷入口（戏台数字档案 / 三维古建展厅 / 红色湘昆文化馆 / 乡村文旅商城）；动态数据看板（收录戏台数、红色旧址戏台数、研学接待人次、文创销售额）；湘南起义红色戏台专题短片、校地红旅合作新闻。
2. **戏台数字档案馆**：收录 110 座古戏台（原文；当前已收录 **52 座**真实文保台账，全量 110 座待补）；乡镇/文保等级/红色旧址/关键词多条件筛选；单台详情承载建筑史料、红色革命事迹、修缮记录、村民口述音频；台账可导出 PDF/Excel 供乡镇文旅、党史办存档。（可结合古戏台地图，地图另开模块亦可）
3. **三维古戏台数字展厅**：加载轻量化三维模型，720° 自由缩放旋转；点击构件或按键弹出介绍/历史故事（2–3 座即可，1 座也行）。
4. **红色湘昆活态文化馆**：红色戏曲专区（改编湘昆折子戏、革命历史戏台演出视频，一个入口即可）；红色戏台故事互动阅读（可放公众号推文）；线下红旅活动预告（红色党课、非遗体验、戏曲汇演排期）。
5. **乡土共创交互平台**：红色记忆投稿通道（老照片/口述/短视频 → 后台审核 → 公开展示）；活化建言留言板（自动分类归档、可导出提交文旅局/党史办）；线上答题（随机抽 10 题，通关领文创电子优惠券）。
6. **研学预约服务中心**：两类套餐（中小学红色思政、高校非遗建筑实践，展示行程/课件/师资）；团体线上预约表单（后台自动生成预约单）；研学成果线上展示。
7. **乡韵文创助农商城**：文创专区（明信片/徽章/红色戏台周边，线上下单、线下自提/同城配送）；农特产联动（烤烟、手工陶艺等，农户代销，收益反哺戏台修缮）；优惠交互（答题/投稿领券，下单抵扣）；订单简易后台（查看订单、核销优惠、营收统计公示）。
8. **分级权限管理后台**：游客（浏览/答题/投稿/预约/下单/留言）；项目团队（上传素材、审核投稿、管理预约、处理订单、导出报表）；政企文旅管理员（新增戏台史料、发布官方活动、查看营收台账、导出文物/红色档案）。
9. **AI 智能问答助手·台小湘**（尽力项）：按资料回答简单问题；或固定问题答案库；实在不行可不做 → 已按「固定问答库」方案实现。

## 2. 技术定位

- **产品形态**：响应式网页（手机 / 电脑浏览器直接访问）
- **技术栈**：pnpm monorepo —— `apps/web`（React 18 + Vite 5 + AntD 5 + React Router 6 + Axios）+ `apps/api`（Cloudflare Workers + Hono + D1 + JWT/jose + bcryptjs）
- **后端方案**：真实后端，投稿/审核/预约/订单/留言全部写入 D1，跨设备可见
- **认证与权限**：JWT（httpOnly cookie）+ 三级权限。后台（2026-08-21 调整）：**admin 政企文旅管理员仅 戏台档案/活动预告/订单**；**team 项目团队拥有全部管理项**（含首页影像、首页动态、投稿审核、研学、题库等）；游客走前台公开能力
- **素材方案（2026-09 变更）**：官方素材与用户投稿**全部走 R2**（桶 `xiangcun-xintai-assets` 分目录）；仅 logo 与 geojson 数据留本地打包，见 §7.5
- **部署**：`wrangler deploy --env production`（API）+ `wrangler pages deploy dist`（Web）
- **成本**：Cloudflare 免费额度（Workers 10 万请求/天、D1 5GB、Pages 静态无限）—— 0 元起步

## 4. 路由设计

**前台**：`/` 首页（Hero 全屏滑窗 → 守护故事 → 影像与动态）｜ `/archive` `/archive/:id` 档案馆与详情｜ `/map` 数字地图（ArcGIS 交互地图 + 专题图集）｜ `/3d` 三维展厅｜ `/culture` 文化馆｜ `/community` 共创｜ `/study` 研学｜ `/mall` 商城。**台小湘 AI 助手为全站悬浮组件**（左下角气泡、窗口可拖拽，不占路由；后台 `/admin` 不显示）。

**后台**（`/admin` + AdminLayout，菜单按角色渲染）：`login` `dashboard` ｜ **admin 可见**：`stages` `activities` `orders` ｜ **team 全量**：`stages` `red-plays` `films`（首页影像）`news`（首页动态）`articles` `activities` `submissions` `suggestions` `quiz` `bookings` `products` `orders` `faq`。

## 5. 数据库设计（D1，16 张表，见 `apps/api/migrations/0001_init.sql`）

- `admins`：管理账号，role(`team`/`admin`)

- `red_plays`：红色戏曲/演出视频（R2 `videos/` 直链 mp4，待素材）
- `articles`：互动阅读
- `activities`：活动排期
- `submissions`：投稿 + 审核状态
- `suggestions`：建言 + 分类归档
- `quiz_questions`：题库
- `bookings` / `study_plans` / `study_results`：研学三表
- `products` / `orders` / `coupons`：商城三表
- `faq_entries`：AI 固定问答
- `news`：校地合作新闻

## 7. 真实数据接入规范

- **戏台台账（已落地，52 座）**：`ancient_stages.geojson`（ArcGIS 文保数据）→ `seeds/real_stages.sql` 导入 **42 座文保戏台**；`戏台详细数据补充`（`scripts/gen-stages-v2.mjs`）→ `seeds/real_stages_v4.sql` **追加补充 10 座**（吉冲头/步云/车溪/仙堂/船山/官仓/逢塘/屈塘/四友/麻布），并回填既有戏台的宗祠/文保批次/保护现状原文/建成年份/尺寸史料（`【补充史料】` 追加，不覆盖原文）；字段映射：文保标题→名称、乡镇、Heritage_Level→文保等级（暂无→未定级）、时代→年代、简介→史料、DD 坐标→经纬度、图片→封面
- **戏台图片（已落地）**：`stage-images/` 42 张实拍图随包部署（压缩 1600px q80 + 600px 缩略图），`cover_url = /assets/map/stage-images/{文件名}` 一一对应；补充 10 座暂无坐标与实拍图（待提供）
- **红色旧址（字段已就绪）**：`is_red_site` 标记列与档案馆「红色旧址」筛选已上线；GeoJSON 未含红色标注，当前 52 座均为 0，待按红色革命事迹台账标注
- **地图（已落地）**：`/map` ArcGIS 交互地图（桂阳县域边界 + 42 点位按文保等级着色 + 弹窗档案/照片）+ 6 张专题图集（乡镇/年代/文保/集聚/保存状态/研学线路）
- **3D（OBJ 直接导入）**：OBJ 模型 + MTL/贴图放入 `apps/web/public/assets/models/`，three.js OBJLoader 加载；单文件 ≤25MiB，超限拆分或压缩（程序化占位兜底）
- **素材命名**：`模块_类型_编号`（如 `stage_photo_001.jpg`），官方素材打包进 `apps/web/public/assets/`
- **视频（R2 直链，方案变更）**：演出视频统一放 R2 `videos/` 目录，`<video src="/api/files/videos/xxx.mp4">` 播放（不再用 B 站裸 iframe）；素材提供后接入

## 7.5 素材存储方案（2026-09 变更：R2 全量，Pages 仅 logo/数据）

- **R2 桶 `xiangcun-xintai-assets` 分目录（✅ 全量落地）**：`hero/` 首页滑窗 ｜ `xitai_photos/` 戏台实拍+缩略图 ｜ `maps/` 专题图 ｜ `trend_cover/` 资讯封面（待素材）｜ `videos/` 演出视频（待素材）｜ `placeholder_img/` 品牌占位图 ｜ `uploads/` 游客投稿。访问经 `/api/files/...`（长缓存、自动 Content-Type）。
- **团队上传接口**：`POST /api/files/upload`（需登录，目录白名单、文件名消毒）；游客走 `POST /api/upload`（仅 `uploads/`，MIME 白名单 ≤100MB）。
- **外链 URL 录入**：后台快速补充素材（保留作补充）。
- **占位图策略**：无真实素材的封面统一指向 `placeholder_img/placeholder_img.png`（红底「素材占位·待补充」）。
- **保留本地打包**：logo（品牌件）、geojson（数据文件，非展示素材）。
- **图片加速（✅）**：`/api/files/*` 输出一年 immutable 缓存；xitai_photos 带 600px 缩略图，列表/弹窗用 `thumbUrl()` 取缩略图 + 懒加载。

> 关键判断：**打包方案解决「官方素材展示」**，**R2 解决「运行期上传」**，两者并存不冲突。
> **视频决策（2026-09 更新）**：弃 B 站方案，演出视频放 R2 `videos/` 目录直链 mp4 播放；后续若要求「不公开/无跳转/自适应清晰度」再评估 **Cloudflare Stream**（$5/1000 分钟存储起，需外币卡）。

## 8. 风险与对策

- **R2 用量与费用**·低：免费额度内；官方素材一次性迁移后以读取为主（缓存 + 直链），游客上传有类型/大小白名单
- **演出视频素材缺失**·待定：R2 `videos/` 目录已建，待提供 mp4 后接入 `<video>` 直链；如需私有/转码再评估 Stream
- **3D 真实建模**·待定：OBJ 文件导入（≤25MiB/文件），超限拆分或压缩；程序化占位兜底
- **线上支付**·不纳入：下单 = 预约单 + 自提/同城配送，优惠券码抵扣
- **企微通知**·不纳入：先站内待处理标识，webhook 后续可选
