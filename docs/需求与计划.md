## 1. 需求（九大模块）

> 原文标注：黑色体尽量实现（有入口即可）；灰色/括号内为可暂缓项。当前 P0–P12 已全部实现入口与主流程，剩余为真数据填充与打磨。

1. **首页·总门户**：红旅主题视觉（红色戏台 + 湘昆非遗双主线）；四大快捷入口（戏台数字档案 / 三维古建展厅 / 红色湘昆文化馆 / 乡村文旅商城）；动态数据看板（收录戏台数、红色旧址戏台数、研学接待人次、文创销售额）；湘南起义红色戏台专题短片、校地红旅合作新闻。
2. **戏台数字档案馆**：收录 110 座古戏台；乡镇/文保等级/破损程度多条件筛选；单台详情承载建筑史料、红色革命事迹、修缮记录、村民口述音频；台账可导出 PDF/Excel 供乡镇文旅、党史办存档。（可结合古戏台地图，地图另开模块亦可）
3. **三维古戏台数字展厅**：加载 glb 轻量化模型，720° 自由缩放旋转；点击构件或按键弹出介绍/历史故事（2–3 座即可，1 座也行）。
4. **红色湘昆活态文化馆**：红色戏曲专区（改编湘昆折子戏、革命历史戏台演出视频，一个入口即可）；红色戏台故事互动阅读（可放公众号推文）；线下红旅活动预告（红色党课、非遗体验、戏曲汇演排期）。
5. **乡土共创交互平台**：红色记忆投稿通道（老照片/口述/短视频 → 后台审核 → 公开展示）；活化建言留言板（自动分类归档、可导出提交文旅局/党史办）；线上答题（随机抽 10 题，通关领文创电子优惠券）。
6. **研学预约服务中心**：两类套餐（中小学红色思政、高校非遗建筑实践，展示行程/课件/师资）；团体线上预约表单（后台自动生成预约单）；研学成果线上展示。
7. **乡韵文创助农商城**：文创专区（明信片/徽章/红色戏台周边，线上下单、线下自提/同城配送）；农特产联动（烤烟、手工陶艺等，农户代销，收益反哺戏台修缮）；优惠交互（答题/投稿领券，下单抵扣）；订单简易后台（查看订单、核销优惠、营收统计公示）。
8. **分级权限管理后台**：游客（浏览/答题/投稿/预约/下单/留言）；项目团队（上传素材、审核投稿、管理预约、处理订单、导出报表）；政企文旅管理员（新增戏台史料、发布官方活动、查看营收台账、导出文物/红色档案）。
9. **AI 智能问答助手·台小湘**（尽力项）：按资料回答简单问题；或固定问题答案库；实在不行可不做 → 已按「固定问答库」方案实现。

## 2. 技术定位

| 项目 | 决策 |
|---|---|
| 产品形态 | 响应式网页（手机 / 电脑浏览器直接访问） |
| 技术栈 | pnpm monorepo：`apps/web`（React 18 + Vite 5 + AntD 5 + React Router 6 + Axios）+ `apps/api`（Cloudflare Workers + Hono + D1 + JWT/jose + bcryptjs） |
| 后端方案 | 真实后端：投稿/审核/预约/订单/留言全部写入 D1，跨设备可见 |
| 认证与权限 | JWT（httpOnly cookie）+ 三级权限：游客 / team（项目团队）/ admin（政企文旅管理员） |
| 素材方案 | 占位图过渡 → R2 上传（未开通前用外链 URL 录入，见 §6 风险） |
| 部署 | `wrangler deploy`（API）+ `wrangler pages deploy dist`（Web） |
| 成本 | Cloudflare 免费额度（Workers 10 万请求/天、D1 5GB、Pages 静态无限）—— 0 元起步 |

## 4. 路由设计

**前台**：`/` 首页长滚动（Hero→四大入口→数据看板→专题短片→新闻）｜ `/archive` `/archive/:id` 档案馆与详情｜ `/3d` 三维展厅｜ `/culture` 文化馆（戏曲/阅读/活动）｜ `/community` 共创（投稿/建言/答题）｜ `/study` 研学中心｜ `/mall` 商城｜ `/ai` 台小湘。

**后台**（`/admin` + AdminLayout，菜单按角色渲染）：`login` `dashboard`（统计/营收）｜ `stages`（政企）｜ `red-plays` `articles` `quiz` `faq` `products` `submissions`（团队）｜ `activities` `suggestions` `bookings` `orders`（团队+政企）。

## 7. 真实数据接入规范

- 戏台台账 Excel/CSV → 后台「戏台档案」页录入或批量导入（`lng/lat` 为真实地图预留）
- 素材命名：`模块_类型_编号`（如 `stage_photo_001.jpg`），存 R2 `assets/` 前缀
- 视频嵌入白名单：`player.bilibili.com` / `v.qq.com` / `www.youtube.com`

## 8. 风险与对策

| 事项 | 状态 | 对策 |
|---|---|---|
| R2 上传需支付方式（外币卡） | 高 | 上传 API 为 stub；管理端直接录入外链 URL，功能不受阻；开通后启用 R2 |
| 视频/音频素材缺失 | 待定 | 封面 + 外链 iframe 白名单；口述音频待采集 |
| 3D 真实建模 | 待定 | 程序化占位模型，后续替换 glb |
| 线上支付 | 不纳入 | 下单 = 预约单 + 自提/同城配送，优惠券码抵扣 |
| 企微通知 | 不纳入 | 先站内待处理标识，webhook 后续可选 |
